## Overview
Geowars is a 2D point and click, shooter game where the player scores points by shooting at shapes that randomly appear on the screen.

## Build & Play
#### Build From Source

First clone the `geowars` repository, then create a separate `build` directory at the same directory level as `geowars` but not inside the `geowars` directory. 
- This "out of source" build allows for separation of the binary tree files (generated by CMake) and the source files (the `geowars` directory).

Then, `cd` (change directory) into the `build` directory before using the following CMake commands:
```
cmake -D BUILD_GAME::BOOL=ON ../geowars/

cmake --build .
```
Using your file explorer, navigate to the `build` directory you created and open 'geowars_game'.

#### Playing Geowars
Use the AWSD keys to move your player shape around the screen. `A` is to move left, `D` to move right, `W` to move up, and `S` to move down.

Use your mouse to control the direction of your bullets. Then, click your left mouse key to shoot a bullet. When you have sucessfully killed an enemy shape it will be removed from your screen and your score on the bottom left will increase.

To pause the game, use `spacebar`.

To end your game press `Esc` or close the window.

## Building Tests
After closing the `geowars` respository, continue to create a `build` directory as you would for building the game, including navigating into your new 'build' directory before proceeding. However, you will use the CMake command listed below.
```
cmake -D GEOWARS_BUILD_TESTS::BOOL=ON ../geowars/

cmake --build .
```

### Continuous Integration
#### Supported Environments & Compilers
CI workflows currently build and unit test on g++ (through Ubuntu), MSVC (through Windows), and Clang (through macOS).

### Requirements
##### C++ Standard
C++ 20 is the minimum required C++ standard.
##### CMAKE
CMake is Geowars build system. You will need CMake installed on your machine to build Geowars from source. Directions on how to install CMake can be found [here](https://cmake.org/download).
### List of Dependencies
##### SFML
SFML is multi-media library used for window, system, and graphics handling. CPM.cmake will automatically download SFML if it is not already installed.
##### CPM.cmake
[CPM.cmake](https://github.com/cpm-cmake/CPM.cmake) is used for dependency management. The CMake build has been configured to download CPM from its GitHub respository if it is not already installed, along with all other dependencies such as SFML.
